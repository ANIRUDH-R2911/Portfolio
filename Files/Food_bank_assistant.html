01 · Overview

Making Food Inventory Easier to Search

Food bank inventory can contain a wide range of donated products, ingredients, allergens, and nutrition information. Finding suitable items by manually checking individual records can be time-consuming for volunteers.

The Accessible Food Bank Assistant turns structured food inventory into a searchable knowledge base. Volunteers can ask questions in natural language such as finding foods containing soy or identifying high-protein options—and receive results grounded in the available inventory data.

The application combines Gemini-based information extraction, hybrid retrieval, and constraint-aware filtering in a read-only Streamlit interface. The public demo is designed to support search without allowing user interactions to modify the persistent inventory.

03 · Architecture

How the Application Works

AI & Data Layer

  • Gemini-powered structured food information extraction
  • Schema validation and ingredient / allergen normalization
  • Inventory records stored in a structured JSON dataset

Retrieval & Application Layer

  • BM25 keyword retrieval and dense semantic retrieval
  • ChromaDB vector storage with Sentence Transformer embeddings
  • Reciprocal Rank Fusion and constraint-aware filtering
  • Gemini answer generation grounded in retrieved evidence
  • Read-only Streamlit interface for volunteer queries
01

Food Data Extraction

Gemini processes food information and extracts structured fields such as ingredients, allergens, and nutrition values.

02

Validation & Normalization

Extracted records are checked against the inventory schema, with generalized nutrient aliases and normalized ingredient / allergen terms.

03

Hybrid Indexing

Inventory documents are indexed for BM25 keyword matching and dense semantic retrieval using Sentence Transformer embeddings and ChromaDB.

04

Query Routing & Filtering

Queries are routed to the appropriate search path. Nutrition, ingredient, and allergen constraints are applied to refine candidate results.

05

Evidence-Grounded Response

Retrieved inventory evidence is formatted for the volunteer, with Gemini-based natural-language generation available behind a controlled configuration.

06

Deployment

The Streamlit application exposes a read-only search experience and initializes or reuses the inventory retrieval index.

05 · Reliability

Designed for a Safe Public Demo

Usage Controls

  • Session-level query limit
  • Daily Gemini generation budget
  • Generation disabled by default
  • Bounded generation timeout

Data Protection

  • Read-only public inventory experience
  • No user-upload workflow in the public demo
  • Persistent inventory protected from UI changes
  • Existing vector index reused when available

What This Project Demonstrates

This project brought together Generative AI, information retrieval, structured data processing, and application deployment to address a practical nonprofit workflow. Beyond integrating an LLM, the work involved evaluating retrieval quality, implementing domain-specific constraints, and adding operational safeguards for a public-facing application.
